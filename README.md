# Hill Cipher — GitHub Pages

Versi ini dibuat khusus agar bisa langsung dijalankan sebagai website statis di GitHub Pages.

## Upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload `index.html` dan `foto.jpg` ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan dan tunggu proses deployment selesai.

## Catatan
Versi GitHub Pages ini tidak membutuhkan PHP, MySQL, MariaDB, `api.php`, `db.php`, atau `database.sql`.

Riwayat kalkulator dan profil disimpan di browser menggunakan `localStorage`, sehingga fitur tersebut tetap dapat digunakan pada GitHub Pages.
